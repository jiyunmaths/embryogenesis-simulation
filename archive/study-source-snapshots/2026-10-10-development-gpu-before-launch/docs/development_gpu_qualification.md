# Development GPU: prospective single-cleavage qualification

This is the first gate toward fresh-zygote experiments. The accepted mature PyTorch/CUDA sources remain unchanged and continue to reject cleavage. A separate `DevelopmentGpu` backend supports a zero-polarity initial cell, progressive ring mechanics, volume correction, changing cell count and mandatory numerical inheritance. No scientific fresh-development cohort is launched by this qualification.

## Numerical and biological contract

PyTorch owns resident arrays, chemical matrix operations, volume projection and occupancy partition. Custom CUDA computes mechanics, the contractile ring and spatial geometry/polarity. Reactions use the accepted compensated SSP-RK2 equations, conservative volume-weighted contact transport and error-free dilution. Beginning-geometry splitting remains first order.

The ring follows the existing progressive annular potential, smooth ramp, moving cell center, stored cleavage axis/offset and shrinking ring radius. The mother remains one chemical compartment until neck and overlap criteria permit abscission. This well-mixed mother assumption omits chemical gradients between connected lobes. Unresolved divisions are not forcibly completed. Isolated single-cleavage axes are prescribed as numerical controls, not as spontaneous symmetry breaking.

The phase pair represents `phi_visible + phase_carry`. Forces and measured transport capacities use visible float32 fields, as in the mature method. Pressure correction transforms the represented field with the existing bounded interface-local scalar correction and retains a new float32/float64 pair. It does not reset carry. Its stopping tolerance is the existing 1e-7 of mother volume. During abscission, partition represented occupancy, invert h to daughter phase fields, and retain each daughter rounding residual. This extends the old numerical projection/splitting to preserve carry; it is not claimed to be byte-identical to historical cleavage.

The chemical pair represents `concentration - chemical_correction`. Scale the mother pair by its measured volume divided by the sum of measured daughter volumes. Add paired, clipped zero-mean partition draws using each daughter's measured volume fraction, with zero volume-weighted mean. Apply error-free multiplication to preserve the correction. All other cell pairs are retained. Daughter targets partition the mother target using measured daughter fractions, with the second target computed as the exact remainder; this preserves the common relative pressure error without imposing 50:50 targets. Both daughters inherit the mother's polarity vector. IDs, lineage, three RNG streams, due times, event metadata, carry and chemical correction survive checkpoints, including checkpoints during a live furrow.

An independent NumPy reference implements the developmental force, correction, partition and chemistry. Its CPU geometry/transport/polarity definitions remain the existing model definitions. Zero-polarity cells use the same conservative face-flux expression as polar cells; this avoids switching float32 versus float64 stencil arithmetic as polarity appears. Historical native CPU arithmetic is additionally checked over a short prefix. Neither reference substitutes for a full developmental spatial-convergence study.

## Fixed synthetic design

Sixteen cases: axes (1,0,0) and normalized (1,2,3), four mechanical branches, and dt=0.00375/0.001875. The branches are coupling off; activity-dependent tension/adhesion only; directional polarity tension only; and the full combination. Chemistry and polarity remain active in all four. Material contrasts are 0.25/0.35 and polarity contrast 0.35 where enabled.

Each case starts from an independently sampled analytic radius-0.4 diffuse cell, grid 72 cubed, domain half-width 2.24 and interface width 0.085. A continuous radial quadrature supplies the common volume target. Initial chemistry is spatially uniform (activator 1.03, inhibitor 0.98), exposing reaction/dilution arithmetic without assigning identities. Axial cells have zero polarity; oblique cells have the specified test vector (0.08,0.03,-0.02), exercising anisotropic ring mechanics. Seed 7 supplies repeatable qualification draws; signal partition noise is 0.001. These synthetic repetitions are **zero new scientific histories**. Initiate one division at time zero, cap at two cells and observe through t=3 every 0.03 units.

## Declared acceptance gates

Every case receives a complete NumPy reference and a historical native 0.06-unit prefix. Maximum full CPU/GPU chemical log discrepancy ≤1e-5; polarity component error ≤1e-5; relative axis error ≤1e-4; relative cell-volume and operator errors ≤1e-5; final phase-field absolute error ≤2e-5. Native-prefix phase error ≤2e-5 and chemical log error ≤1e-5. Eight independent NumPy chemical/dilution steps on actual evolving GPU geometry must agree within 1e-11. The mature no-cleavage branch must agree bitwise with the accepted backend for eight steps, including corrections and geometry.

Complete one resolved division per case. Event time differences between backends ≤2dt; finest/coarse GPU event time difference ≤0.0075. Compare cellwise quantities at observations with identical IDs; allow at most one explicitly reported observation to straddle slightly different abscission times. At all observations, including unmatched ones, compare ancestor-averaged concentrations (≤1e-5 log error) and total species amounts (≤1e-5 relative error). Final daughter IDs must agree. This rule is fixed before running and avoids silently applying a cellwise comparison across a change in cell count.

At the event boundary, species amount and target-volume relative jumps must be ≤2e-14; visible occupancy-volume jump ≤1e-6; maximum represented occupancy discrepancy ≤1e-14. Every-step dilution closure ≤2e-14. Every-step volume error <5%, equivalent radius ≥4 grid intervals, zero mechanical clipping; boundary occupancy <0.01 at observations. Nondividing daughters must each have one connected component at phi≥0.5; a pinching mother's lobes are excluded. Check eight bitwise uninterrupted-versus-restored steps at t=0.45 during division and immediately after abscission, retaining tensors, cell count, targets, lineage, event and RNG state.

The eight two-timestep GPU comparisons retain the mature moving limits: chemical/polarity/axis/operator error ≤0.01, relative cell-volume error ≤0.005 and final phase error ≤0.02. Whole species-amount error ≤0.005 and ancestor-averaged chemical log error ≤0.01. Allow at most one reported observation straddling an event. This is two-level qualification, not an estimated convergence order. A failure remains recorded; thresholds are not relaxed after inspecting results.

Sources, input arrays and runtime binaries are pinned before the qualification. Four independent CPU reference workers may run alongside one serial GPU coordinator on the qualified GTX 1080 Ti UUID. Missing correction/schema fields or invalid arrays cause an error, with no silent zero initialization or CPU fallback. Original scientific sources, accepted results, ledger and manuscript remain preserved.
